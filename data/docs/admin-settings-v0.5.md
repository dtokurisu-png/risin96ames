# RISIN96AMES Admin + Settings v0.5

Esta versión agrega:

- Menú de tres rayitas.
- Settings.
- Cambio tema oscuro/claro.
- Página admin con código local.
- Generador de ficha JSON para cargar juegos manualmente.
- Página para solicitar agregar juego mediante GitHub Issue.

## Advertencia técnica

Como RISIN96AMES está en GitHub Pages sin backend, el login admin no es seguridad real de servidor.
La seguridad real es que solo el dueño del repo puede hacer commit/push.

Código temporal admin por defecto:

```txt
RISIN96ADMIN
```

Puedes cambiarlo en:

```txt
js/admin.js
```
