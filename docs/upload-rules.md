# Upload Rules - Futuro sistema de juegos externos

En la primera versión no se permite subida pública de juegos.

Cuando se active esta función, las reglas base serán:

- El juego debe venir en `.zip`.
- Debe contener un `index.html`.
- Debe ser un juego HTML ejecutable en navegador.
- No debe incluir `.exe`, `.bat`, `.cmd`, `.msi`, `.scr` ni ejecutables peligrosos.
- No se publicará automáticamente.
- Toda solicitud debe pasar revisión manual.
- El admin podrá aprobar, rechazar o pedir cambios.
