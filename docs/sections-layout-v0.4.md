# RISIN96AMES Sections Layout v0.4

Esta versión reorganiza la home para que se vea más limpia y distribuida por secciones.

## Cambios principales

- La primera pantalla ahora se siente como una sección hero completa.
- Las estadísticas se movieron a la esquina superior derecha, integradas en la barra superior.
- El botón de feedback se quitó del hero principal.
- La sección de juegos ahora funciona visualmente como un carrusel horizontal.
- Las reseñas quedan como una sección independiente.
- El comienzo de comunidad queda como otra sección independiente.

## Archivos que reemplaza

```txt
index.html
css/styles.css
```

Esta versión mantiene compatibilidad con:

js/app.js
