# Rising Games — Cartera de conceptos y continuidad
**Actualizado:** 2026-11-08
**Repositorio:** Rising Games (risin96ames). Este índice documenta conceptos, no declara juegos programados o publicados.

## Proyectos nuevos
1. [MiniMundos](minimundos/GAME_DESIGN_V0_1.md) — **prioridad de producción.** Universo familiar cooperativo 3D de islas conectadas, juegos/minijuegos heterogéneos basados en motores reutilizables, jardín/granja, edificios y mejoras, exploración, mascotas tipo Tamagotchi, plantas estratégicas defendidas de insectos, dificultad adaptada al perfil, ayudantes para jugar solo, progresión persistente y cosméticos. Sin competitividad obligatoria. **Deseo de contenido:** 10–15 minijuegos en el primer mundo, nuevos mundos mensuales; objetivo aspiracional bajo limitaciones reales de tiempo. Prototipo jugable para enero 2027.
2. [RING: LEGACY](ring-legacy/GAME_DESIGN_V0_1.md) — boxeo estilizado técnico/competitivo, entrenamiento real, campaña, versus, clasificatorias mundiales, cosméticos sin pay-to-win. Proyecto posterior.
3. [WILDBOUND: The Lost Frontier](wildbound-the-lost-frontier/GAME_DESIGN_V0_1.md) — supervivencia y cacería persistente de amigos, construcción cooperativa, criaturas territoriales, zonas de encuentros y PvPvE opcional, base compartida y progresión individual. Proyecto posterior.

## Reglas de gestión
- **Nunca combinar los sistemas centrales de estos tres juegos** solo porque compartan franquicia/editorial o repositorio documental.
- Las fichas contienen decisiones, hipótesis, riesgos y pendientes; actualizar al avanzar el diseño. Mantener versión o historial para evitar perder acuerdos.
- Las referencias a éxitos comerciales son inspiraciones de experiencia; no copiar IP protegida.
- Desarrollar cada juego en proyecto/código independiente del portal Rising Games, sin alterar juegos actuales.
- Para MiniMundos, buscar una vertical slice sólida y modular antes de prometer 10–15 minijuegos terminados en ~64–120 horas; no sobredimensionar una entrega prevista para enero.
- Monetización responsable y privacidad infantil por diseño.
