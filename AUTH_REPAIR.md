## Prepared implementation

Use one real Wix HTML Component with ID `r96App` on the Risin96ames page. The page adapter binds this exact component before assigning the frontend URL. No global scripts, injected overlays, URL redirects, tokens, Nexo helpers, or backend changes are required. The frontend and adapter must both be version 3.1.0.

The protocol pins the parent origin, checks window identity, versions messages and request IDs, drops stale replies, acknowledges the login request, and restores the controls on cancellation or errors. Member information is display-only, never an authorization grant.

## Independence limitation

Native Wix Members authentication belongs to the Wix SITE. Two pages in Nexo's site share its member session even if their source code is separate. This implementation does not meet a requirement for separately signed-in identities between Rising and Mi Espacio. Strict session independence requires a separate Wix site/member context; confirm and provision that context before releasing if this remains the requirement. Do not simulate separation by hiding the current member or clearing Nexo's session.
