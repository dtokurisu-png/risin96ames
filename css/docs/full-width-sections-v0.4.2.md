# RISIN96AMES Full Width Sections v0.4.2

Esta versión convierte la home en bandas horizontales que ocupan todo el ancho de la pantalla.

## Idea visual

- Cada sección se extiende de izquierda a derecha.
- El contenido se distribuye a lo largo del ancho, no como una columna centrada.
- El hero divide título grande a la izquierda y texto/acción a la derecha.
- Juegos es una vitrina horizontal full-width.
- Reseñas y comunidad tienen sus propias bandas separadas.
