# Plantilla de tarjeta de juego

Cada tarjeta debe mostrar:

```txt
Imagen / banner
Nombre del juego
Descripción corta
Estado
Versión
Género
En prueba
Valoración
Cantidad de reseñas
Botón Ver detalles
Botón Jugar
```

## Ejemplo genérico

```txt
Beta Test Game

Una experiencia beta genérica para comprobar la estructura inicial de RISIN96AMES antes de cargar juegos reales.

Estado: Beta
Versión: 0.1.0
Género: Experimental
En prueba: Flujo de juego, botón jugar y reseñas demo
Valoración: Pendiente
Reseñas: 0
```
